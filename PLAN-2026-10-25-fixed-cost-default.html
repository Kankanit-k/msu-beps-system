1สรุป

  • เปลี่ยนหลักใหญ่: ตอนนี้ถ้าคณะยังไม่ล็อกวิธีปันส่วน หน้าปรับปรุงหลักสูตรจะไปต่อไม่ได้ (“คณะ…ยังไม่ได้ล็อกวิธีปันส่วนต้นทุนคงที่ — รอผู้ดูแลคณะ”) · มติใหม่: ไม่ต้องบังคับ ให้ใช้ค่าของปีก่อนหน้า ถ้าไม่มีเลยใช้ค่าตามแบบจำลอง Excel
  • ค่าตาม Excel มีอยู่แล้ว: “หารรายหัว แยกตามระดับการศึกษา” (DEFAULT_ALLOC_CHOICE) ให้ตัวเลขเท่ากับชีต (ยืนยันไว้ 14 ต.ค.) จึงไม่ต้องสร้างวิธีใหม่
  • ข้อ 2.1 ทำไว้แล้ว: การเลือกวิธีอยู่ที่หน้าตั้งค่า /admin/fixed-cost-lock ระดับคณะ · หน้าปรับปรุงหลักสูตรแสดงอย่างเดียว ไม่มีตัวเลือก
  • กฎการล็อกเปลี่ยน: ตอนนี้ “ล็อก” = คณะกดเองและปลดเองได้ · ใหม่: คณะบันทึกการตั้งค่า แก้ได้อิสระ จนกว่ามีหลักสูตรในคณะกดยืนยันฉบับจริงในปีนั้น → ล็อกการตั้งค่าของปีนั้นทันที แก้ต้องทำบันทึกขออนุมัติ
  • เพิ่ม: ตารางเทียบในหน้าคำนวณ “ถ้าหารตามหลักสูตร / ถ้าหารรายหัว ตัวเลขเป็นเท่าไร” (ข้อ 2.2)
  • ยังเก็บใน localStorage เหมือนเดิม (งานฐานข้อมูลแยก)

2มติ vs ของเดิม

ข้อในเอกสารตอนนี้รอบนี้
1 · ไม่บังคับเลือก ไม่ล็อกระบบไม่ล็อก = คำนวณไม่ได้ (pickBlocker, NoLockAlert)แก้
1 · ไม่ได้ตั้งค่าปีนี้ → ใช้ค่าปีก่อนหน้าไม่มี (อ่านเฉพาะคีย์ปีนี้ 2568|คณะ)เพิ่ม
1 · ปีแรก → ค่าตาม Excelมีค่า DEFAULT_ALLOC_CHOICE (หารรายหัวตามระดับ) แต่ใช้เฉพาะตอนไม่มี lock ในบางจุดใช้เป็นค่าตั้งต้นจริง
2.1 · ปันส่วนระดับคณะ อยู่ในเมนูตั้งค่ามีแล้ว (FixedCostLockView) · หน้าคำนวณแสดงอย่างเดียวคง
2.1 · เจ้าหน้าที่คณะ + ผู้บริหารคณะ ตั้งค่าร่วมกันตั้งได้: deptAdmin, universityAdmin · facultyExec เข้าหน้าตั้งค่าไม่ได้D5
2.2 · เทียบตัวเลข หารตามหลักสูตร vs หารรายหัวไม่มี (การ์ดปันส่วนแสดงเฉพาะวิธีที่ใช้)เพิ่ม
2.3 · ยืนยัน/พิมพ์ฉบับจริง → ล็อกการตั้งค่าปีนั้นการล็อกคณะไม่เกี่ยวกับการยืนยันเอกสาร · คณะปลดเองได้ทุกเมื่อเพิ่ม
2.3 · เปลี่ยนหลังล็อก → บันทึกขออนุมัติ—ปลดได้เฉพาะกองแผน

3ลำดับการหาวิธีปันส่วนที่ใช้ (ปี × คณะ)

  1. คณะตั้งค่าของปีนี้ไว้ → ใช้ค่านั้น · ป้าย คณะตั้งค่า ปี 2568
  2. ไม่ได้ตั้งปีนี้ → ย้อนหาปีก่อนหน้าที่ใกล้ที่สุดที่คณะตั้งไว้ (2567 → 2566 …) · ป้าย ใช้ค่าปี 2567 (ยังไม่ได้ตั้งปีนี้)
  3. ไม่เคยตั้งเลย → หารรายหัวแยกตามระดับการศึกษา (= แบบจำลอง Excel) · ป้าย ค่าเริ่มต้นตามแบบจำลอง Excel
ค่าปีก่อนที่ใช้ไม่ได้กับปีนี้ (เช่น กำหนด % รายหลักสูตร แต่มีหลักสูตรใหม่/ปิดไป ทำให้ผลรวมไม่ครบ 100) → ตกไปใช้ค่าตาม Excel พร้อมคำเตือนให้คณะเข้าไปตั้งค่า (D3)
  • ทำเป็นฟังก์ชันเดียว resolveFacultyPolicy(year, faculty) ใน lockStore.ts คืน { choice, source: 'config' | 'prev-year' | 'default', fromYear, locked } · useFacultyLock ใช้ตัวนี้ → หน้าปรับปรุง/เปิดใหม่/ห้องจำลอง (useFacultyAllocation) ได้กฎเดียวกันหมดโดยไม่ต้องแก้ทีละหน้า
  • ปีที่มีในระบบตอนนี้: 2566, 2567, 2568 (MOCK_RUN.budgetYears)

4กฎการล็อกใหม่ (สถานะการตั้งค่าของคณะต่อปี)

สถานะเกิดเมื่อคณะแก้ได้?หน้าคำนวณ
ยังไม่ตั้งไม่มีค่าปีนี้ตั้งได้คำนวณได้ ใช้ค่าปีก่อน/Excel
ตั้งค่าแล้วคณะกด “บันทึกการตั้งค่า”แก้ได้อิสระคำนวณได้ ใช้ค่าคณะ
🔒 ล็อกแล้วหลักสูตรแรกของคณะกด “ยืนยันและพิมพ์ฉบับจริง” ในปีนั้นไม่ได้ — บันทึกขออนุมัติ → กองแผนปลดคำนวณได้ ใช้ค่าที่ล็อก
  • ตอนยืนยัน ถ้าค่าที่ใช้มาจากปีก่อน/Excel → บันทึกค่านั้นลงเป็นการตั้งค่าของปีนี้แล้วล็อก (กันคณะมาตั้งค่าย้อนหลังจนตัวเลขในเอกสารที่ยืนยันแล้วไม่ตรง)
  • เก็บว่าล็อกเพราะเอกสารไหน (หลักสูตร · เวลา · ผู้ยืนยัน) แสดงในหน้าตั้งค่า
  • หน้าตั้งค่า: เปลี่ยนคำ “ล็อก” → “บันทึกการตั้งค่า” · “ปลดล็อก” ของคณะหายไป เหลือ “ปลดล็อก (กองแผน)” เฉพาะ universityAdmin พร้อมกล่องยืนยัน · ถ้ามีเอกสารยืนยันแล้ว ปลดแล้วเอกสารเดิมยังคงตัวเลขเดิม (ภาพ ณ ตอนยืนยัน)
  • ข้อความเตือนทั้งหมดที่บอก “ต้องรอคณะล็อกก่อน” ใน NoLockAlert, หน้าตั้งค่า, คำอธิบายเมนู ปรับใหม่

5ตารางเทียบวิธีปันส่วน (หน้าคำนวณ · ข้อ 2.2)

การ์ดปันส่วน (ขั้นที่ 1, หุบได้): วิธีที่ใช้ หารรายหัวนิสิต · ใช้ค่าปี 2567 · ปุ่ม “เทียบวิธีปันส่วน ▾”
วิธีต้นทุนคงที่ของหลักสูตรนี้Q* รวมแผ่นดินQ* ไม่รวมกำไร/ขาดทุนผล
หารรายหัวนิสิต ✓ ที่ใช้…………ไม่คุ้ม
หารเท่ากันทุกหลักสูตร… (± ต่างจากที่ใช้)…………
กำหนด % เองแสดงเมื่อคณะกรอกสัดส่วนไว้แล้วเท่านั้น
คิดจากตัวเลขหลังปรับปรุงของผู้ใช้ (Q / ค่าเทอม / ต้นทุนผันแปร) · ข้อมูลอ้างอิงเท่านั้น เปลี่ยนวิธีที่หน้านี้ไม่ได้ · ผู้ดูแลคณะมีลิงก์ “ไปตั้งค่า”
  • ใช้ allocateFaculty(scenario, policyOf(choice)) ตัวเดิม เรียกวิธีละครั้ง · วิธีหารรายหัวทำให้ต้นทุนคงที่ขยับตามจำนวนนิสิต จึงต้องคิดสดตามตัวเลขที่แก้
  • วางในการ์ดปันส่วนเดิม (FixedCostAllocationCard) ไม่เพิ่มการ์ดใหม่ · หน้าตั้งค่าของคณะใช้ตารางเดียวกันเทียบทั้งคณะ (ระดับหลักสูตรทุกตัว) ก่อนบันทึก
  • รายงาน PDF: ไม่ใส่ตารางเทียบ (เอกสารแสดงวิธีที่ใช้จริงอย่างเดียว) — D6

6ข้อสรุป (ยืนยันแล้ว 25 ต.ค. — ตามข้อเสนอทั้ง 7 ข้อ)

D1 · ค่าตั้งต้นปีแรก “ตามแบบจำลอง Excel”ใช้ หารรายหัวแยกตามระดับการศึกษา ซึ่งได้ตัวเลขเท่าชีตแท็บ 3
แนะนำ: ใช้ค่านี้
D2 · อะไรทำให้การตั้งค่าล็อก(ก) หลักสูตรแรกในคณะกดยืนยันฉบับจริงในปีนั้น · (ข) คณะกดล็อกเองแบบเดิม · (ค) ทั้งสองอย่าง
แนะนำ: (ก) ตามเอกสารข้อ 2.3 — ก่อนมีเอกสารยืนยัน คณะแก้ได้อิสระ
D3 · ค่าปีก่อนใช้กับปีนี้ไม่ได้ (กำหนด % แต่หลักสูตรเปลี่ยน)
แนะนำ: ตกไปใช้ค่าตาม Excel + เตือนคณะ · ไม่เดาสัดส่วนให้หลักสูตรใหม่เอง
D4 · ใครปลดล็อกหลังมีเอกสารยืนยัน
แนะนำ: กองแผน (universityAdmin) เท่านั้น หลังได้รับบันทึกขออนุมัติ — แบบเดียวกับปลดล็อกเอกสาร
D5 · ผู้บริหารคณะในหน้าตั้งค่าเอกสารเขียน “ให้เจ้าหน้าที่ระดับคณะและผู้บริหารคณะเป็นผู้ตั้งค่าร่วมกัน” แต่มติ 5 ระดับ (21 ต.ค.) ให้ผู้บริหารคณะไม่มีเมนูตั้งค่า
แนะนำ: ผู้บริหารคณะเปิดดูหน้าตั้งค่าของคณะตนได้ (อ่านอย่างเดียว + ตารางเทียบ) · เจ้าหน้าที่คณะเป็นคนกดบันทึก — “ร่วมกัน” คือตกลงในที่ประชุมคณะ
D6 · ตารางเทียบวิธีปันส่วนในรายงาน PDF
แนะนำ: ไม่ใส่ — เอกสารเสนอแสดงเฉพาะวิธีที่ใช้ กันสับสน
D7 · คณะเปลี่ยนการตั้งค่าหลังมีร่างที่บันทึกไว้แล้ว
แนะนำ: เปิดร่างกลับมาคิดใหม่ตามค่าปัจจุบัน + แถบแจ้ง “วิธีปันส่วนเปลี่ยนจากตอนบันทึก (เดิม: … )” · เอกสารที่ยืนยันแล้วไม่เปลี่ยน

7ลำดับงาน

  1. FC-1 resolveFacultyPolicy + สถานะ (ยังไม่ตั้ง / ตั้งแล้ว / ล็อก) ใน lockStore.ts · useFacultyLock คืนค่าที่ใช้จริงเสมอ + test ลำดับการหาค่า (ปีนี้ → ปีก่อน → Excel, ค่าปีก่อนใช้ไม่ได้)
  2. FC-2 หน้าปรับปรุง/เปิดใหม่: เอา blocker “ต้องรอคณะล็อก” ออก · การ์ดปันส่วนแสดงป้ายแหล่งที่มาของค่า · ปรับ NoLockAlert เป็นแถบแจ้งเบาๆ (ไม่บล็อก) พร้อมลิงก์ไปตั้งค่าสำหรับเจ้าหน้าที่คณะ
  3. FC-3 ยืนยันฉบับจริง → บันทึกค่าที่ใช้เป็นการตั้งค่าปีนั้น + ล็อก (เก็บหลักสูตร/ผู้ยืนยัน/เวลา)
  4. FC-4 หน้าตั้งค่า: “บันทึกการตั้งค่า” แทน “ล็อก” · สถานะ 3 แบบ · ปลดล็อกเฉพาะกองแผน · ผู้บริหารคณะดูได้ (D5)
  5. FC-5 ตารางเทียบวิธีปันส่วน ในการ์ดปันส่วน (หน้าคำนวณ) และหน้าตั้งค่า
  6. FC-6 ทดสอบในเบราว์เซอร์: คณะไม่เคยตั้ง / ตั้งปี 2567 อย่างเดียว / ตั้งปีนี้ / ล็อกหลังยืนยัน / กองแผนปลด × 3 บทบาท · agent แยกตรวจ
  7. อัปเดตความจำ: กฎ “อาจารย์ต้องรอคณะล็อก” (12 ต.ค.) ถูกแทนด้วยมตินี้
