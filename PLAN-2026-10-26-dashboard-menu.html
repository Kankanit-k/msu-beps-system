1สรุป

  • หมวด Dashboard = หน้าสรุปภาพรวมอย่างเดียว: ภาพรวมมหาวิทยาลัย · ภาพรวมคณะ (ไม่มีเมนูย่อยอีก)
  • หน้า รายได้ · ต้นทุน/ค่าใช้จ่าย · จุดคุ้มทุน ที่ตอนนี้เป็นเมนูย่อยใต้ “ภาพรวมคณะ” ยกขึ้นมาเป็นหมวดของตัวเอง
  • แถบหัวของ 2 หน้า Dashboard ตอนนี้ประกอบเองคนละแบบ (ตัวกรองคณะ/ระดับ/ปีไม่เหมือนกัน) → รวมเป็น คอมโพเนนต์แถบหัวเดียว แต่ละหน้าแค่เลือกว่าจะโชว์ช่องไหน
  • ระยะแรก ไม่เปลี่ยน URL (/faculty/revenue ฯลฯ ยังเดิม) — ย้ายแค่ตำแหน่งในเมนู ลิงก์ที่แชร์ไปแล้วไม่พัง

3ชื่อหมวดใหม่ (รายได้ · ต้นทุน · จุดคุ้มทุน)

ต้องไม่ชนกับหมวดเดิม “เจาะลึกจุดคุ้มทุน” (ย้อนหลัง 5 ปี) และ “วิเคราะห์จุดคุ้มทุน” (จำลอง) — จึงเลี่ยงคำว่า เจาะลึก / วิเคราะห์

ตัวเลือกข้อดีข้อสังเกต
ผลการดำเนินงาน แนะนำศัพท์ที่กองแผน/ผู้บริหารใช้อยู่แล้ว · บอกว่าเป็นตัวเลขจริงของปีนี้ ไม่ใช่การจำลอง—
รายงานรายด้านสื่อว่าเป็นตาราง/รายละเอียดแยกด้าน คู่กับ Dashboard ที่เป็นภาพสรุปคำว่า “รายงาน” อาจถูกเข้าใจว่าเป็น PDF export
การเงินรายด้านสั้น ตรงเนื้อหาจุดคุ้มทุนไม่ใช่ “การเงิน” ตรงตัวนัก
ข้อมูลรายมิติกลาง ๆ ใช้ได้ยาวฟังเป็นศัพท์ระบบ ผู้บริหารอาจไม่คุ้น

4แถบหัวของหมวด Dashboard

ปัญหาของหัวตอนนี้

เรื่องภาพรวมมหาวิทยาลัยภาพรวมคณะ
ระดับการศึกษาทุกระดับ / ตรี / โท / เอกตรี / โท / เอก (ห้ามรวม — ไม่มี “ทุกระดับ”)
คณะ“กรองคณะ” เลือกได้หลายคณะเลือกได้ 1 คณะ (เฉพาะระดับ ม.)
ปีปีงบประมาณปีการศึกษา + ⓘ
ล้างตัวกรองมีไม่มี
ชิปวันที่ข้อมูลยาวมาก (“ข้อมูล ณ วันที่ 14/10/2569 เวลา 15:16”) กินที่จนตัวกรองตกบรรทัดบนจอแคบ

ข้อเสนอ: แถบหัว 2 แถว ใช้คอมโพเนนต์เดียว

แถว 1 = “กำลังดูอะไร + ผลลัพธ์” · แถว 2 = “ตัวกรอง” — ติดหัวจอเหมือนเดิม

ภาพรวมมหาวิทยาลัย
ภาพรวมมหาวิทยาลัย ข้อมูล ณ 14 ต.ค. 69 15:16 49,744 นิสิต ส่วนเกิน 150.5 ลบ.
รวมเงินแผ่นดินไม่รวมเงินแผ่นดิน ระดับ: ทุกระดับ ▾ คณะ: ทุกคณะ ▾ ปีการศึกษา 2568 ▾ ✕ ล้างตัวกรอง
ภาพรวมคณะ (ผู้บริหารคณะ — คณะล็อก แสดงเป็นชื่อ ไม่ใช่ช่องเลือก)
ภาพรวมคณะ› คณะวิทยาการสารสนเทศ ข้อมูล ณ 14 ต.ค. 69 15:16 1,204 นิสิต ขาดทุน 3.2 ลบ.
รวมเงินแผ่นดินไม่รวมเงินแผ่นดิน ระดับ: ปริญญาตรี (12) ▾ ปีการศึกษา 2568 ▾

กติกาของแถบหัว

  • ช่องเดียวกัน ลำดับเดียวกันทุกหน้า: ฐานรายได้ → ระดับ → คณะ → ปี → ล้างตัวกรอง · หน้าไหนไม่ใช้ช่องไหนก็ซ่อน ไม่สลับที่
  • ตัวกรองค้างข้ามหน้า: เลือกฐานรายได้/ปี ที่ภาพรวมมหาวิทยาลัยแล้วกดไปภาพรวมคณะ ค่ายังอยู่ (เก็บใน URL query เพื่อแชร์ลิงก์ได้)
  • คลิกคณะจากภาพรวมมหาวิทยาลัย (แท่งกราฟ/แถวตาราง) → เปิดภาพรวมคณะของคณะนั้นทันที
  • ชิปผลลัพธ์อยู่ขวาแถว 1 ตามตัวกรองเสมอ · วันที่ข้อมูลย่อเป็นตัวอักษรเล็กข้างชื่อ
  • มือถือ: แถว 2 ยุบเป็นปุ่ม “ตัวกรอง (3)” เปิดแผงจากด้านล่าง
  • หมวดผลการดำเนินงาน ใช้แถบหัวตัวเดียวกัน + ชิปเฉพาะหน้า (รายได้รวม / ต้นทุนรวม + ป้ายปีงบของต้นทุน) ตามที่มีอยู่แล้ว

5ต้องตัดสินใจ

D1 · ชื่อหมวดใหม่ผลการดำเนินงาน / รายงานรายด้าน / การเงินรายด้าน / อื่น ๆ
ข้อเสนอ: “ผลการดำเนินงาน”
D2 · หน้า รายได้/ต้นทุน/จุดคุ้มทุน ดูได้ระดับไหนเมื่อไม่ได้อยู่ใต้ “ภาพรวมคณะ” แล้ว ผู้ใช้ระดับมหาวิทยาลัยอาจคาดว่าจะเห็นทั้งมหาวิทยาลัย (ก) คงเป็นรายคณะเหมือนเดิม — ย้ายเมนูอย่างเดียว · (ข) เพิ่มตัวเลือก “ทั้งมหาวิทยาลัย” ในช่องคณะสำหรับบทบาทระดับ ม. (งานเพิ่ม: ตาราง/กราฟต้องรองรับมุมรวม)
ข้อเสนอ: (ก) ก่อน แล้วค่อยถามที่ประชุมกองแผนว่าต้องการ (ข) หรือไม่ — หมายเหตุ: เคยตกลงว่าไม่มี “ทุกคณะ” บน /faculty
D3 · ป้ายปีบนหัวภาพรวม ม. เขียน “ปีงบประมาณ” แต่ภาพรวมคณะเขียน “ปีการศึกษา” ทั้งที่เป็นชุดข้อมูลเดียวกัน
ข้อเสนอ: ใช้ “ปีการศึกษา” ทุกหน้า + ⓘ อธิบายว่าต้นทุนเป็นรอบปีงบ (เหมือนหน้าคณะตอนนี้)
D4 · URLคง /faculty/revenue ฯลฯ หรือเปลี่ยนเป็น /performance/revenue
ข้อเสนอ: คงเดิม — เปลี่ยนเฉพาะเมนูกับหัวข้อ breadcrumb (“ผลการดำเนินงาน › รายได้ — คณะ…”)
D5 · ตัวกรองค้างข้ามหน้าใช้ทั้ง 5 หน้า (2 Dashboard + 3 หน้าใหม่) หรือเฉพาะในหมวด
ข้อเสนอ: ทั้ง 5 หน้า — ฐานรายได้ · ปี · คณะ ค้างไว้ · ระดับ “ทุกระดับ” จะกลายเป็นระดับแรกของคณะเมื่อเข้าหน้าคณะ (เพราะห้ามรวมระดับ)
