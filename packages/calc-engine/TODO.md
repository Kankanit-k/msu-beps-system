## สิ่งที่ตัดสินใจแล้ว — เขียนตามนี้ได้เลยเมื่อเริ่ม Sprint 1

1. **สูตรหลัก** (จาก SA.md หัวข้อ 7.1 · ยืนยันกับโค้ด prototype แล้วในหัวข้อ 16.3)

   ```
   TC  = TFC + TVC
   R   = TR / Q          → null เมื่อ Q <= 0
   AVC = TVC / Q         → null เมื่อ Q <= 0
   CM  = R - AVC
   Q*  = TFC / CM        เมื่อ CM > 0                    (สูตร 1)
   Q*  = TC / R          เมื่อ CM <= 0 → full_cost_recovery (สูตร 7)
   BE Revenue = Q* × R                                   (สูตร 4)
   MoS = TR - BE Revenue
   π   = TR - TC                                         (สูตร 3)
   ```

2. **ฐานรายได้ 2 กรณี** (สูตร 5a/5b) — ต้นทุนเท่ากันทั้งสองกรณี เปลี่ยนเฉพาะฝั่งรายได้

   ```
   with_government    : TR = governmentBudget + incomeBudget
   without_government : TR = incomeBudget
   ```

3. **Q\* ระดับที่สูงกว่าหลักสูตร** (สูตร 6a/6b) — ค่าหลักคือ `sum_of_programs`
   ต้องคืนทั้งสองค่าเพื่อให้ UI เทียบได้ และบันทึก `qstar_method` ลง `BREAK_EVEN_RESULT`

4. **สถานะ `CM <= 0` ต้องไม่แสดงว่า "ผ่านจุดคุ้มทุน"** — prototype เก่าเขียน
   `isOk = !Qs || Q >= Qs` ซึ่งทำให้กรณีแย่ที่สุดขึ้น ✓ (SA.md หัวข้อ 16.3 ข้อ 3)
   ให้แยกสถานะ `full_cost_recovery` ออกมาชัดเจนตามที่ v8 ทำ

5. **Golden test** — ใช้ตัวเลขจาก **v8 + ไฟล์ `20260711_จุดคุ้มทุน update.xlsx`** เท่านั้น
   ห้ามใช้ตัวเลขจาก `MSU-BEPS_03June26-1.html` เป็นค่าอ้างอิง (TC ต่างกัน 762.8 ลบ.)

   ค่าอ้างอิงระดับมหาวิทยาลัยจาก v8:

   | ตัวแปร | ค่า                 |
   | ------ | ------------------- |
   | Q      | 48,695 คน           |
   | TR     | 2,448.7 ลบ.         |
   | TC     | 2,415.8 ลบ.         |
   | TFC    | 1,488.6 ลบ. (61.6%) |
   | TVC    | 927.2 ลบ. (38.4%)   |
