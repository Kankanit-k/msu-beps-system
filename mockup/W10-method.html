📐 สูตรและหลักวิชาการจุดคุ้มทุน (Break-Even Analysis)

📌 สูตรที่ 1 — จุดคุ้มทุน

Q* = TFC / ( R − AVC )

จุดคุ้มทุน (BEP) คือจำนวนนิสิตขั้นต่ำ Q* ที่ทำให้ TR = TC พอดี (π = 0) ส่วนต่าง (R − AVC) คือ Contribution Margin (CM) — รายได้ส่วนที่นำไปชดเชย TFC ยิ่ง CM สูง จุดคุ้มทุนยิ่งต่ำ

📌 สูตรที่ 2 — ต้นทุนรวม

TC = TFC + ( AVC × Q )

ต้นทุนรวมมี 2 ส่วน คือ TFC (ไม่เปลี่ยนตาม Q) และ TVC = AVC × Q (แปรผันตาม Q) มมส. มีสัดส่วน TFC สูงถึง 61.6% ทำให้ ATC ลดลงเมื่อ Q เพิ่ม (Economies of Scale)

📌 สูตรที่ 3 — กำไร / ขาดทุน

π = TR − TC = (R − AVC) × Q − TFC

ส่วนเกิน/ขาดทุน (π): เมื่อ Q > Q* กำไรเพิ่มในอัตรา CM ต่อหน่วย · เมื่อ Q < Q* จะขาดทุน

📌 สูตรที่ 4 — รายได้ ณ จุดคุ้มทุน

BE Revenue = Q* × R

รายได้ขั้นต่ำเพื่อไม่ขาดทุน ใช้วางแผนงบประมาณและกำหนดเป้ารับนิสิต · Margin of Safety = TR จริง − BE Rev — ยิ่งกว้างยิ่งมั่นคง

📌 สูตรที่ 5 — ฐานรายได้ 2 กรณี (ตามไฟล์ต้นฉบับ)

R รวมแผ่นดิน = (งบแผ่นดิน + งบเงินรายได้) / Q
R ไม่รวมแผ่นดิน = งบเงินรายได้ / Q

แยกวิเคราะห์ 2 กรณีเพราะงบประมาณเงินแผ่นดินเป็นเงินอุดหนุนจากรัฐ ไม่ใช่รายได้ที่มหาวิทยาลัยหามาเอง

รวมเงินแผ่นดิน — สะท้อนสถานะการเงินตามจริง (งบที่ได้รับทั้งหมด)  ·  ไม่รวมเงินแผ่นดิน — สะท้อนความสามารถพึ่งพาตนเอง หากถูกตัดงบอุดหนุนจะอยู่รอดหรือไม่

ต้นทุน (TFC, TVC, AVC) เท่ากันทั้ง 2 กรณี — เปลี่ยนเฉพาะฝั่งรายได้ ทำให้ CM และ Q* ต่างกัน

📌 สูตรที่ 6 — จุดคุ้มทุนระดับคณะ (2 วิธี)

วิธีหลัก: Q*คณะ = Σ Q*หลักสูตร i

วิธีผลรวมรายหลักสูตร (ค่าหลัก) — หา Q* ของแต่ละหลักสูตรก่อน แล้วนำมาบวกกัน แต่ละหลักสูตรต้องคุ้มต้นทุนคงที่ของตัวเอง ชดเชยข้ามหลักสูตรไม่ได้ → เข้มงวดและตรงกับการบริหารจริง

วิธีเทียบ Q* = TFCคณะ / (R − AVC) ใช้ยอดรวมทั้งคณะ ยอมให้หลักสูตรกำไรอุ้มหลักสูตรขาดทุน → ได้ Q* ต่ำกว่าจริง

📌 สูตรที่ 7 — กรณี CM ≤ 0

ถ้า (R − AVC) ≤ 0 → Q* = TC / R

เมื่อ AVC > R (ต้นทุนผันแปรต่อหัวสูงกว่าค่าเทอมต่อหัว) ตัวส่วนของสูตรมาตรฐานจะติดลบ ได้ Q* ติดลบซึ่งไม่มีความหมาย จึงใช้หลัก Full-Cost Recovery — หาว่าต้องรับนิสิตกี่คนค่าเทอมรวมจึงครอบคลุมต้นทุนทั้งหมด

ตัวอย่าง — เคมี (คณะวิทยาศาสตร์): TC ≈ 2.16 ล้านบาท · ค่าเทอม ≈ 93,000 บ./คน → Q* = 2,163,604 / 93,311 ≈ 23 คน

⚠ ค่าที่ได้เป็นเป้าหมายขั้นต่ำ ไม่ใช่จุดคุ้มทุนจริง — ทางแก้ที่ยั่งยืนคือลด AVC หรือขึ้นค่าธรรมเนียม

📖 คำนิยามตัวแปรในสูตร

สัญลักษณ์ชื่อและความหมายหน่วยมมส. (ข้อมูลอัพเดท)
Q / Q*จำนวนนิสิตจริง / ณ จุดคุ้มทุน · Q = ลงทะเบียนจริง, Q* = TFC / (R − AVC)คน—
TRรายได้รวม (Total Revenue = R × Q) · งบแผ่นดิน + งบเงินรายได้ (ค่าธรรมเนียม)บาท—
TCต้นทุนรวม (Total Cost = TFC + TVC) · ต้นทุนทางตรงและทางอ้อมที่ปันส่วนมาบาท—
TFCต้นทุนคงที่รวม · เงินเดือน ค่าเสื่อมราคา ปันส่วนสำนักงานเลขานุการบาท—
TVC / AVCต้นทุนผันแปร / ต่อหน่วย · AVC = TVC / Qบาท / บาท/คน—
Rรายได้ต่อหน่วย (Revenue per Student = TR / Q)บาท/คน—
πกำไร/ขาดทุน · π > 0 = ส่วนเกิน, π = 0 = BEP, π < 0 = ขาดทุนบาท—

📌 หมายเหตุ: ลำดับชั้นการวิเคราะห์ & "ภาควิชา"

ระบบรวมข้อมูลจากล่างขึ้นบน: หลักสูตร (230) → ระดับการศึกษาในแต่ละคณะ (ปริญญาตรี / บัณฑิตศึกษา) → คณะ (20) → มหาวิทยาลัย ทุกตัวเลขระดับบนคือผลรวมของหน่วยย่อย ส่วน R, AVC, Q* คำนวณใหม่จากยอดรวมของหน่วยนั้น
