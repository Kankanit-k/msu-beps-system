1ข้อสรุป

  • ของเดิมที่ที่ประชุมชมให้คงไว้: กราฟเป้าหมาย vs นิสิตจริง (เส้นทึบ/เส้นประ) · สีสถานะ · ตารางก่อน | หลังปรับ · ปุ่มเรียงอันดับ
  • ส่วนที่ต้องเพิ่ม: การ์ด KPI 5 ใบ · บรรทัดรวมทั้งคณะในตาราง · กราฟจุดตัดคุ้มทุนเชิงตัวเงิน (ใช้ BreakEvenLineChart ตัวเดียวกับหน้าภาพรวมคณะ)
  • ส่วนที่ต้องแก้: สเกลแกน X · เปลี่ยนตัวเลือกระดับจาก dropdown เป็นแท็บ (เปลี่ยนที่ LevelSwitch ตัวเดียว ได้ครบทุกหน้าย่อย) · หัวตารางบอกฐานรายได้
  • สาเหตุจริงของแกน X ยาว ไม่ได้มาจากยอดนิสิตรวมคณะอย่างที่เอกสารคาดไว้ แต่มาจากจุดคุ้มทุนกรณี “ไม่รวมเงินแผ่นดิน” (สัตวศาสตร์ 1,573 คน) ถ้าตั้งแกนสูงสุด 500–600 คนตามที่ประชุมเสนอ เส้นประจะตกขอบไป 3 จาก 6 หลักสูตร (สัตวศาสตร์ อาหารฯ เกษตรฯ) จึงเสนอวิธีอื่นในข้อ 3
  • ข้อ 3.4 (บันทึกผลลงฐานข้อมูล) เป็นงานโครงสร้างระบบ ตอนนี้ยังไม่มีฐานข้อมูลที่ใช้งานจริงต่ออยู่ ทั้งประวัติการจำลองและการล็อกวิธีปันส่วนยังเก็บใน localStorage จึงแยกไปทำเป็นงานของตัวเอง (ข้อ 9-D4)

2มติที่ประชุม vs ของเดิม

ข้อในเอกสารตอนนี้ที่ประชุมขอรอบนี้
1 · กราฟเป้าหมาย vs นิสิตจริงมีคงไว้คง + แก้สเกล
1 · สีสถานะ / ป้าย “ไม่ผ่าน”มีคงไว้คง
1 · ตารางก่อน | หลังปรับ + ปุ่มเรียงมี (RankingCard)คงไว้คง + เพิ่มแถวรวม
2.1 · การ์ด KPI 5 ใบมีแค่ชิปเล็กมุมขวา (1,482 นิสิต · ขาดทุน 10.9 ลบ.)นิสิตปัจจุบัน · Q* รวมแผ่นดิน · Q* ไม่รวมแผ่นดิน · ขาดอีกกี่คน · ผ่าน/ไม่ผ่านกี่หลักสูตรเพิ่ม
2.2 · แถวรวมทั้งคณะในตารางไม่มีนิสิตรวม + กำไร/ขาดทุนรวม (เดิม vs ใหม่)เพิ่ม
2.3 · กราฟจุดตัดคุ้มทุน (เส้นรายได้ × เส้นต้นทุน)มีบนหน้าภาพรวมคณะ ไม่มีในหน้านี้แสดงในหน้านี้ หรือแท็บสลับกับกราฟจำนวนคนเพิ่ม (ใช้ของเดิม)
3.1 · สเกลแกน Xแกนยาวให้พอกับค่าสูงสุดของ นิสิตจริง / Q* ทั้ง 2 กรณี × 1.08แกนพอดีกับหลักสูตรในระดับนั้นแก้ (ข้อ 3)
3.2 · แท็บระดับแทน dropdowndropdown “ระดับ” ในแถบด้านบนแท็บ ตรี (6) | โท (4) | เอก (4)แก้ทุกหน้าย่อย
3.3 · ตารางตามปุ่มสลับฐานรายได้ตารางขยับตามฐานรายได้อยู่แล้ว (buildProgramCrossData(…, mode)) แต่หัวตารางไม่บอกว่าใช้ฐานไหนขยับตาม หรือบอกฐานที่หัวตารางเพิ่มป้ายฐาน
3.4 · ผลหลังปรับเก็บลงฐานข้อมูลlocalStorage (historyStore.ts)Database log แยกปีการศึกษา ดูได้จากทุกเครื่องแยกเป็นงานใหญ่

3ข้อค้นพบ: แกน X ยาวเพราะอะไร

คณะเทคโนโลยี ป.ตรี (6 หลักสูตร) ปีงบ 2568 ตัวเลขจากระบบ:

แกนสูงสุดตอนนี้ = 1,573 × 1.08 ≈ 1,699 ซึ่งคือเส้นประของสัตวศาสตร์ ไม่ใช่ยอดนิสิตรวมคณะ เส้นประทั้งหมดอยู่จริงที่ 351–1,573 คน ถ้าตัดแกนที่ 500–600 ตามข้อเสนอ จะเหลือเส้นประบนจอแค่ 3 หลักสูตร และหลักสูตรใหญ่ที่สุดจะหายไปทั้งหมด

ข้อเสนอ: แกนตามฐานรายได้ที่เลือก + ป้ายบอกค่าที่เกินขอบ
  • ฐาน “รวมเงินแผ่นดิน”: แกนสูงสุด = max(นิสิตจริง, Q* รวมแผ่นดิน) × 1.1 → ประมาณ 500 คน แท่งยืดเต็มจอ เห็นส่วนต่างชัด
  • เส้นประที่เกินขอบ → วาดหัวลูกศร ▸ ชิดขอบขวา พร้อมตัวเลข “ไม่รวมแผ่นดิน 1,573” (ค่าจริงยังอยู่ใน tooltip)
  • ฐาน “ไม่รวมเงินแผ่นดิน”: แกนขยายให้ครอบเส้นประทั้งหมด แท่งสั้นลงตามจริง ซึ่งเป็นภาพที่ผู้บริหารควรเห็นว่าห่างเป้าแค่ไหน
  • ผูกการทำงานกับปุ่มสลับฐานรายได้ข้อ 3.3 → กราฟ การ์ด และตารางขยับพร้อมกันทั้งหน้า

5รายละเอียดแต่ละส่วน

5.1 การ์ด KPI 5 ใบ ใช้ KpiTile + ScrollTile แบบหน้ารายได้/ต้นทุน · ค่าหลัก = ระดับที่เลือก (ข้อ 9-D2) · บรรทัดล่าง = ทั้งคณะ
  • ① นิสิตปัจจุบัน = Σ Q ของหลักสูตรในระดับ
  • ② / ③ Q* = levelRes ของแต่ละฐาน (ผลบวก Q* แบบชีต ตามที่ตกลงไว้ว่า “Q* ยึด Excel”) · ใบของฐานที่ไม่ได้เลือกแสดงสีจางลง
  • ④ ยังขาด = ผลรวมของส่วนที่ขาดเฉพาะหลักสูตรที่ยังไม่ถึงเป้า (ข้อ 9-D3) · ถ้าถึงหมดแสดง “ถึงจุดคุ้มทุนครบ” สีเขียว
  • ⑤ ผ่าน / ไม่ผ่าน / ไม่มีจุดคุ้มทุน (Q* ≤ 0) · กดแล้วกรองตารางเฉพาะกลุ่มที่ไม่ผ่าน (แบบตัวกรอง “คงที่เกินเกณฑ์” ในหน้าต้นทุน)
5.2 กราฟเป้าหมาย vs นิสิตจริง แก้ xmax ใน TargetVsActualChart ตามข้อ 3 · เส้นที่เกินขอบใช้ annotation (point ที่ขอบขวา + label) · กราฟนี้ใช้บนหน้า landing ด้วย จึงแก้ครั้งเดียวได้ทั้งสองหน้า
5.3 กราฟจุดตัดคุ้มทุน นำ BreakEvenLineChart ที่ใช้บน landing มาใช้ (res = levelRes, palette = BE_LINE) · วางเป็นแท็บที่ 2 คู่กับกราฟจำนวนคน (ตามที่ประชุมเสนอ หน้าจะได้ไม่ยาวเกิน 2 จังหวะ) · ⓘ บอกว่าจุด Q* ที่ปักไว้คือผลบวก Q* รายหลักสูตรแบบชีต
5.4 ตารางอันดับ + แถวรวม เพิ่ม prop summary ใน RankingCard (ใช้ร่วมกับหน้า cross ของมหาวิทยาลัย จึงต้องไม่มีผลเมื่อไม่ได้ส่งมา) · นิสิตใหม่และกำไรใหม่ของหลักสูตรที่ไม่มีผลหลังปรับ = ค่าเดิม · แสดงส่วนต่าง “+x.x ลบ.” สีเขียว/แดง · ชื่อการ์ดต่อท้าย “· ฐาน: รวมเงินแผ่นดิน”
5.5 แท็บระดับ เปลี่ยน LevelSwitch.tsx เป็น MUI Tabs แล้วย้ายออกจาก FacultyStatusBar ลงมาเป็นแถวของตัวเองใต้แถบ · จอแคบใช้ variant="scrollable" · ป้าย “ปริญญาตรี (6)” แบบเดิม · ค่ายังเขียนลง URL ?lvl= เหมือนเดิม
5.6 ข้อความใต้หัวตาราง ระหว่างที่ยังเก็บในเบราว์เซอร์ ให้คงข้อความเตือนไว้ แต่เขียนให้ชัดขึ้น เช่น “ผลหลังปรับยังเก็บในเครื่องนี้เท่านั้น — เครื่องอื่นจะไม่เห็น” จนกว่าจะทำข้อ 9-D4

7ยังไม่ทำรอบนี้

  • ย้ายผลการจำลองและการล็อกวิธีปันส่วนลงฐานข้อมูล (3.4) — งานแยก ดูข้อ 9-D4
  • เป้าหมายแผนรับนิสิตจากกองแผน — ยังรอแหล่งข้อมูล (ตามที่ตกลงไว้ 23 ต.ค.)
  • Export ตารางจุดคุ้มทุน — ที่ประชุมไม่ได้ขอในเอกสารนี้ เพิ่มได้ภายหลังด้วยวิธีเดียวกับ CostTable

8ลำดับงาน

  1. BE-1 แท็บระดับ (LevelSwitch → Tabs, ย้ายออกจากแถบบน) — กระทบทุกหน้าย่อย ทำก่อน
  2. BE-2 สเกลแกน X + ลูกศรค่าเกินขอบ ใน TargetVsActualChart
  3. BE-3 การ์ด KPI 5 ใบ + ตัวกรอง “ไม่ผ่าน”
  4. BE-4 แท็บกราฟ จำนวนคน | จุดตัดคุ้มทุน
  5. BE-5 แถวรวมใน RankingCard + ป้ายฐานรายได้ที่หัวตาราง + ข้อความเตือนเรื่องเครื่องนี้
  6. BE-6 ทดสอบในเบราว์เซอร์: 3 ระดับ × 2 ฐาน × คณะที่มี/ไม่มีผลหลังปรับ × จอแคบ · ตรวจตัวเลขเทียบชีต · ส่ง agent แยกช่วยตรวจ
  7. DB (แยก) ฐานข้อมูลจริง + API บันทึกผลการจำลอง → เปลี่ยน historyStore / lockStore ให้เรียก API (ฟังก์ชันเดิมออกแบบไว้รองรับแล้ว) · ต้องทำ security review ก่อน deploy

9ข้อสรุป (ยืนยันแล้ว 24 ต.ค. — ใช้ตามที่แนะนำทั้ง 5 ข้อ)

D1 · สเกลแกน Xแกนตามฐานที่เลือก + ลูกศรบอกค่าที่เกินขอบ (ข้อ 3) · ทางเลือกอื่น: ตั้งค่าตายตัว 500–600 ตามเอกสาร (เส้นประหาย) / แยกเป็น 2 กราฟตามฐาน (หน้ายาวขึ้น)
แนะนำ: แกนตามฐานที่เลือก
D2 · การ์ดแสดงตัวเลขระดับไหนค่าหลัก = ระดับที่เลือก บรรทัดล่าง = ทั้งคณะ · เพราะกราฟและตารางด้านล่างแยกระดับ ถ้าการ์ดเป็นทั้งคณะ ตัวเลข “ขาดอีก” และ “ผ่าน/ไม่ผ่าน” จะไม่ตรงกับสิ่งที่เห็นข้างล่าง (หน้าต้นทุน/รายได้ใช้ทั้งคณะเป็นค่าหลัก แต่ไม่มีปัญหานี้)
แนะนำ: ระดับที่เลือก
D3 · “ยังขาดอีก” นับแบบไหน(ก) รวมเฉพาะหลักสูตรที่ยังขาด — หลักสูตรที่เกินเป้าไม่หักกลบ · (ข) Q* รวม − นิสิตรวม — หลักสูตรที่เกินเป้ามาหักกลบได้ · คณะเทคโนโลยีได้ 226 เท่ากันทั้งสองแบบเพราะขาดทุกหลักสูตร แต่คณะอื่นจะต่างกัน
แนะนำ: (ก) นิสิตย้ายข้ามหลักสูตรไม่ได้ · แสดง (ข) ใน ⓘ
